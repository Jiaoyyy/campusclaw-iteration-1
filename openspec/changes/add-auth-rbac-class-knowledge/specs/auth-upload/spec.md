## ADDED Requirements

### Requirement: 登录与登出
系统 SHALL 支持教师与学生账号密码登录，验证哈希口令并在服务端管理可撤销会话。

#### Scenario: 正确与错误口令
- **WHEN** 用户输入正确账号口令
- **THEN** 建立会话并进入本班材料页；错误口令不建立会话且不泄露账号存在性

#### Scenario: 未登录访问
- **WHEN** 无有效会话访问材料
- **THEN** 页面跳转登录页，API 返回 401，响应不含材料数据

#### Scenario: 登出后重放
- **WHEN** 用户登出后再次使用旧 Cookie 访问 API
- **THEN** 返回 401，不返回业务数据

### Requirement: 角色权限
系统 SHALL 在服务端限制上传仅教师可执行。

#### Scenario: 学生直接调用上传接口
- **WHEN** 已登录学生携带合法文件和有效 CSRF 令牌调用上传接口
- **THEN** 返回 403，材料表、知识库表和文件目录均无新增

### Requirement: 班级隔离
系统 SHALL 只从服务端用户记录取得班级，限制列表、搜索、详情、下载与上传的数据范围。

#### Scenario: 本班列表与搜索
- **WHEN** A 班用户查询列表或标题搜索
- **THEN** 仅返回 A 班资料，不能通过提交 class_id=B 扩大范围

#### Scenario: 跨班 ID 与文件访问
- **WHEN** A 班用户访问 B 班材料详情或下载链接
- **THEN** 返回与不存在资源相同的 404，不含标题、正文或存储路径

#### Scenario: 上传伪造归属
- **WHEN** A 班教师上传时提交 class_id=B
- **THEN** 不得写入 B 班，归属必须仍为 A 班或请求被拒绝

### Requirement: 上传与知识库入库
系统 SHALL 支持不超过 2 MiB 的非空 UTF-8 txt/md 文件，并保存材料与知识库全文记录。

#### Scenario: 教师上传成功
- **WHEN** 教师提交合法文件
- **THEN** 返回 201，材料与知识库均存在同班关联记录，刷新列表和查询数据库都可验证

#### Scenario: 非法文件被拒绝
- **WHEN** 文件扩展名、编码、正文或大小不符合要求
- **THEN** 返回 400 或超限时 413，数据库和文件目录无新增

#### Scenario: 上传写入中途失败
- **WHEN** 文件写入或双表事务发生可捕获错误
- **THEN** 双表不出现部分记录，已写文件被清理；数据库不可用时返回 503

### Requirement: 材料阅读界面
系统 SHALL 提供数据库驱动的材料列表、标题搜索、详情及鉴权下载，支持主题和视图切换。

#### Scenario: 同班学生阅读
- **WHEN** 学生查看本班材料
- **THEN** 可浏览、按标题搜索、阅读及下载，Markdown 格式正确，恶意 HTML 或链接不能执行脚本

#### Scenario: 切换显示方式
- **WHEN** 用户切换浅色/深色及列表/网格
- **THEN** 显示方式改变，材料内容和权限范围不变

### Requirement: 配置与复现
系统 SHALL 通过单实例 Docker Compose 启动，持久化数据库与文件，提供无认证存活探针且不提交真实密钥。

#### Scenario: 第三方启动与重启
- **WHEN** 第三方按 README 配置环境并启动 Compose，再重启服务
- **THEN** 能打开登录页，重启后已上传资料仍在，GET /health 无需登录返回 200

#### Scenario: 密钥与口令检查
- **WHEN** 检查仓库文件及用户表
- **THEN** 真实密钥和 .env 不在版本管理中，存在 .env.example，口令仅以哈希保存

#### Scenario: 数据库故障
- **WHEN** 已登录用户请求依赖数据库的接口且数据库不可用
- **THEN** 返回 503 而非把依赖故障视为会话失效；/health 仍按进程存活语义响应

### Requirement: 发布证据与归档
提交 SHALL 包含文档、可复核验收证据、版本标记、实际同伴互验记录及通过验证后的 OpenSpec 归档。

#### Scenario: 完成交付审查
- **WHEN** 准备提交仓库
- **THEN** strict 校验通过，逐条 Scenario 有实际结论与证据，三条失败路径均有记录，设计决策与代码一致，同伴验证确已执行，tasks 无虚假勾选，归档后的主规约包含本能力
