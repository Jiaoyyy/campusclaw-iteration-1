## Why

教师需要把讲义提供给本班学生，同时避免其他班级读取资料和学生擅自上传。本轮先建立资料与权限底座，为后续课程的检索和 AI 功能准备真实数据。

## What Changes

- 新增账号密码登录、登出、教师和学生角色。
- 服务端按当前用户班级限制所有材料读取与上传。
- 教师上传 UTF-8 txt/md 文件，保存原文件并将正文写入知识库表。
- 本班用户可查列表、按标题搜索、查看详情和下载；学生不能上传。
- 支持 Markdown 安全渲染、主题和列表/网格切换。
- 提供单实例 Docker Compose、公开存活探针、运行说明与验收证据。

## Capabilities

### New Capabilities
- `auth-upload`: 登录、角色权限、班级隔离和材料入库。

### Modified Capabilities
无；目前没有已有主规约。

## Impact

从零新建应用、数据库、材料存储、测试及容器配置。尚无旧数据迁移。密钥只在服务端环境变量中读取，真实密钥不入库。

## Non-goals

本轮不实现聊天、RAG、智能体、MCP、作业批改、PDF、注册找回密码、SSO、多实例或公网发布。标题搜索不等于后续课程的知识库检索。
